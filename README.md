# NoWork Proxy

Прокси-клиент для Android с **автоматическим переключением серверов**. Проверяет доступность соединения и выбирает подходящий сервер из вашей подписки — полезно при нестабильной доступности серверов в российских сетях.

[**Скачать APK**](https://github.com/usach77/NoWork-Proxy/releases/latest)

- Автопереключение с приоритетом нужной группы серверов.
- Обновление подписок и проверка обновлений приложения.
- Темы оформления и шесть значков, цвета которых следуют за темой.

В **Настройки → Автопереключение** укажите первое слово названий серверов с большим пакетом трафика, например `SMART`, если так их называет ваш провайдер. Это помогает реже задействовать резервные LTE-серверы и расходовать их отдельный лимит.

Для подключения нужна подписка провайдера или собственная конфигурация.
